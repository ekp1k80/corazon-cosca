# Corazón — estudio integrado

Abrí `index.html` en el navegador.

## Controles
- **Espacio**: siguiente punto.
- **Shift + Espacio**: punto anterior.
- **← / →**: imagen anterior/siguiente dentro del punto.
- **↑ / ↓**: también cambian de imagen.
- Click en una miniatura: la vuelve imagen principal.
- Click en un punto del sidebar: salta directamente a ese punto.

Cada carpeta contiene el **MD correspondiente** y las **imágenes seleccionadas** para ese punto.
Los puntos de inervación extrínseca/plexo y drenaje linfático se incluyen con texto, pero sin forzar fotogramas si no aportaban valor visual.


## Cambios incorporados
- Pericardio fibroso: se aclara que es grueso y resistente.
- Lámina parietal del pericardio seroso: se aclara que es extremadamente delgada y no puede separarse del pericardio fibroso por disección.
- Configuración externa: forma de pirámide triangular, orientación, cuatro caras, tres bordes, base posterior y vértice.
- Auditoría de terminología posicional: se reemplazaron expresiones coloquiales por términos anatómicos.
